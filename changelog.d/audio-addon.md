# The Audio add-on

### New
- **The Audio add-on, for installs without Pro.** Volume, mute and off for each room's players on the map, for $6.45 CAD: one payment that covers 2 years, no subscription, up to three homes. Its key goes in Settings → Features → PadSpan licence like any other, and the card then says "PadSpan Audio add-on · until" its date. PadSpan Pro includes it.

### Changed
- **The licence card names an Audio add-on key as such.** It never calls it Pro, offers the add-on once beside Pro to an install without it, and the Forensics card asks for a Pro key as before. Every licence check now says which add-ons this PadSpan knows, so the licence server answers an add-on key only to a PadSpan that can tell it from Pro.

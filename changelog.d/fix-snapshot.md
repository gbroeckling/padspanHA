# Hidden devices stay hidden, labelled devices stay listed, and the device list keeps its order

### Fixed
- **A device hidden by an ingest rule is really left out of the device list.** A rule on a plain device's address, or on its maker's prefix (the `ingest_rules` setting), counted the device as hidden and listed it all the same; only iBeacons and phones with a key were kept out. A hidden device is now left out however it would have been listed: as a plain Bluetooth device, as the Home Assistant entity that tracks it, or from the object history. While it is hidden its place in the object history is kept the way a device that is not being heard is kept: for good if it has a label, and for the object history time (one day unless you changed it) if it has none. Take the rule away and a labelled device is back as it was, first-seen date and all; one without a label that was hidden for longer than that comes back as a new device. The count of hidden devices in the snapshot's summary counts each one once.
- **`excluded_objects` hides a device by its address too.** An entry hid a device only when it was an iBeacon's or a phone's key; a plain device's address hid nothing. An entry can now be written any way the device list shows a device: its address (capitals or small letters), its key (`ble:…`, `ibeacon:…`, `irk:…`, `entity:…`), or, for one beacon of a pack that shares an id, the id followed by that beacon's address.
- **A labelled device that goes quiet stays in the device list.** A plain Bluetooth device you had named, not heard for longer than the object history time, was dropped from the list and came back as a new device the next time it was heard: its name was kept, but the list looked for it under the wrong id and took the device for one nobody had named. It now stays listed, with the date it was first seen. The same goes for a device whose name is held only in PadSpan's device registry.
- **Devices heard at the same moment keep the same order after a restart.** Adverts of exactly the same age came out in an order that changed each time Home Assistant started, and the device list was built in that order. They now go by address.

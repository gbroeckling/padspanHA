# Pick a receiver's room where PadSpan says it has none

### New
- **A receiver with no room gets its room picked right where PadSpan says so.** On the Overview's "Who's where now" and in Setup's receivers step, each receiver with no Home Assistant area now has a room list and "Set room". The room its name points to is already chosen ("esp32-kitchen" → Kitchen; change it if it's wrong). Set room gives the receiver that area in Home Assistant, exactly as the Bluetooth Radios list's Assign Area does, so the room shows everywhere at once. Like Assign Area, anyone in the house can use it; never on a wall screen.

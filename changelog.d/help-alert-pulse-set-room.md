# The help says what Alert pulse watches, and where a receiver's room is set

### Fixed
- **Alert pulse, as the help describes it.** The help said it rings a room for "a door left open". It rings for any door, window, gate or cover left open over 6 hours, and a window or cover open while it rains or snows. Now in English, German, French and Dutch.
- **Who's where now's help names Set room.** It still said to give each receiver its area in Home Assistant; the card has had its own room picker since 0.38.276.

# Add-ons

### New
- **Add-ons, for installs without Pro.** One feature each, one payment that covers 2 years, no subscription, up to three homes: Audio ($6.45 CAD), Alarm & security ($6.45), Wi-Fi coverage ($6.45), Climate map ($8.65), Time travel ($7.55), Vacation Mode & presets ($4.25), Looks pack ($4.25), Forensics ($5.56) and Insights ($5.56). They share one key, entered in Settings → Features → PadSpan licence like any other; the card lists each add-on with its date. PadSpan Pro includes them all.

### Changed
- **The licence card names an add-on key as such.** It never calls it Pro, and offers the add-ons in one list beside Pro to an install without Pro. An install with an add-on key can still start the Pro trial: its key is kept aside and comes back by itself when the trial ends. Every licence check now says which add-ons this PadSpan knows, so the licence server answers an add-on key only to a PadSpan that can tell it from Pro.

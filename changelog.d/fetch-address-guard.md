# A robot vacuum's or ESPresense Companion's address must be on your network

### Fixed
- **The robot vacuum import and the ESPresense Companion import fetch only from your home network.** Both read from the address you type. They also took an address that is this Home Assistant machine itself (`localhost`, `127.0.0.1`) or a link-local one (`169.254.x.x`, where a cloud server answers questions about itself), followed a redirect to any address, and an address with a `?` in it lost the path PadSpan adds, so they fetched the wrong page. Now an address that is, or whose name leads to, this machine, a link-local, multicast or empty address is refused in words before anything is fetched, a redirect is not followed, and a `?` or `#` in the address no longer replaces the path. Addresses on your home network (192.168.x.x, 10.x.x.x, 172.16 to 172.31, fd00::) and names that lead to them work as before. If you saved the Companion's address as `localhost`, use its address on your network instead (for example `http://192.168.1.50:8267`).

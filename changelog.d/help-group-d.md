# Help pages brought up to date (Health, Bluetooth and the expert tools)

### Changed
- **Help for Health, Bluetooth, Monitor, QA, Sandbox, Receivers, History, Events and Install Base rewritten to match the screens as they are now.** Health gets its own "?" and a page explaining every card, Problems found explains all its checks (map geometry, room footprint and room divergence included) with their thresholds, Bluetooth's help lists the five tabs and every Scanners control, and says where a receiver's room is really set (Overview → View radios list, or Mapping → Edit → Radios).
- **New help for the status dot in the top bar and for Diagnostics**, in the Full Manual's new Health section and in Troubleshooting.
- **On-screen pointers fixed:** advice that sent you to "Settings → Presence" or "Settings → Scanner Map" now names Settings → Tracking (and Settings → Tracking → Receivers or the Receivers page for a receiver's offset); "RF barrier" is now "signal wall"; QA's fix hints name Mapping; Sandbox's MQTT row points to Manage → HA Entities; and the support hints on Health, Monitor and Diagnostics say to attach the report to a GitHub issue or an email.

# OS 2 Local for Control4, from inside PadSpan

### New
- **OS 2 Local for Control4, installed from PadSpan.** Cloud services for Control4 OS 2 ended on November 1, 2026, and Home Assistant's built-in Control4 integration logs in through that cloud, so OS 2 controllers stopped working with it. OS 2 Local for Control4 is a separate Home Assistant integration that logs in to the controller itself with its system password and adds room volume, mute and off on OS 2. An administrator can install it from **Settings → Tracking → Home Assistant and integrations → OS 2 Local for Control4**: PadSpan downloads its newest release from GitHub, checks it is the product, backs up any `custom_components/control4` into `padspan_ha/control4_backups/`, and offers Home Assistant's restart (it never restarts by itself). The same card checks for updates and has **Undo**, which puts the backup back or brings back the built-in integration. The Overview offers it when a Control4 entry failed to set up or the controller runs OS 2. PadSpan Pro includes it.
- **A Specialty part on the licence card.** A key holding OS 2 Local for Control4 shows it there, "for life", apart from the feature add-ons. It is never in a sale.

# Control4 OS 2 Local, from inside PadSpan

### New
- **Control4 OS 2 Local, installed from PadSpan.** Control4 ended its cloud services for OS 2 on November 1, 2026, and Home Assistant's built-in Control4 integration logs in through that cloud, so OS 2 controllers stopped working with it. Control4 OS 2 Local is a separate Home Assistant integration that logs in to the controller itself with its system password and adds room volume, mute and off on OS 2. An administrator can install it from **Settings → Tracking → Home Assistant and integrations → Control4 OS 2 Local**: PadSpan downloads its newest release from GitHub, checks it is the product, backs up any `custom_components/control4` into `padspan_ha/control4_backups/`, and offers Home Assistant's restart (it never restarts by itself). The same card checks for updates and has **Undo**, which puts the backup back or brings back the built-in integration. The Overview offers it when a Control4 entry failed to set up or the controller runs OS 2. PadSpan Pro includes it.
- **A Specialty part on the licence card.** A key holding Control4 OS 2 Local shows it there, "for life", apart from the feature add-ons. It is never in a sale.

# Add-ons: fixes before the stable

### Fixed
- **A free year of Pro by invite no longer drops an add-on key.** Claiming the invite on a PadSpan with an add-on key keeps that key aside, the way the 90-day trial does, and puts it back when the year ends. The claim is no longer refused because an add-on key is there.
- **The sale card names Advanced smart lighting** with the other add-ons, and never shows with nothing to name.
- **The add-ons' note on padspan.traks.ca** now just says add-ons need the latest PadSpan (in German too).

### Changed
- **The usage report counts Advanced smart lighting and Robot vacuum like the other add-ons.** The report is still off unless you turn it on. Where Settings' power teams, a power team's card, the Atlas builder or the robot vacuum's import offer one of them, the offer is counted, and so is the power teams' link to it. A key kept aside is reported while any key runs over it.

# One place for "something's wrong"

### New
- **Health says what the status dot says.** Clicking the dot opens Health, which now starts with the dot's own list (a receiver that went silent, positioning that stopped, learning paused), each line with a button to where you look into it: the Receivers page, Diagnostics or the Overview. Before, Health didn't mention most of them.
- **Diagnostics is one click from Health, and sends itself.** Health has "Open Diagnostics" (it was reachable only through QA). Diagnostics has "Email support" and "Open an issue" beside Copy: each copies the same report and opens an email to hello@traks.ca or a new GitHub issue to paste it into (issues are public, so remove personal details first).

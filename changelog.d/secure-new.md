# Enhanced security starts on for a new install

### Changed
- **A new install starts with Enhanced security on.** From its first day, changes to the home's shared setup (clearing calibration, deleting rooms or devices, resets, and the rest of the list under Who can change what) need a Home Assistant administrator, while everyone in the house can still view and use PadSpan. A home that is already set up keeps the switch exactly as it has it; it is under Settings → Tracking → Enhanced security.

# Help brought up to date across PadSpan

### Changed
- **Every screen's help now matches the screen.** Overview, Follow, Devices, phone tracking, Mapping, the Atlas, Settings, Manage, Health, Bluetooth, Calibration, Traceback, Rooms, Setup and the expert tools were rewritten against what they show today: buttons named as they read, where each thing is in Basic, Advanced and Development mode, and no more pointers to tabs that moved (Objects is now Devices → By Room, Maps is Mapping, Settings → Presence is Settings → Tracking).
- **More "?" buttons.** Health, the Rooms and Setup screens, each Settings → Tracking section, Calibration's Results, Guided calibration and Walk a room, Guests, Vacation Mode, wall screens, Live Aboard and the Live/Sample and Basic/Advanced/Dev buttons all have help where they had none. Training's walkthroughs and manual were rewritten to match, each subject told once, and the manual now explains the status dot in the top bar.
- **The map-deletion help was wrong.** It said a deleted map's calibration points could be used again by uploading the map again. They can't be put back on a map: deleting a map in Manage → Data removes the plan and the room shapes drawn on it, and its calibration points stay, on no map, still used for positioning. To remove them too, use that map's Clear in Settings → Scanner Map first.
- **The ESPresense Companion import only adds.** Its help said it updates rooms you already have; it adds new ones and leaves yours alone.
- **Home Assistant entity names shown as they really are.** Manage → HA Entities and the help showed IDs like sensor.padspan_car_keys_area; a named device's entities are device_tracker.car_keys, sensor.car_keys_area, sensor.car_keys_distance and one sensor.car_keys_distance_… per receiver. The ready-to-paste templates there now find PadSpan's sensors by integration, so they work as written.
- **Smaller corrections:** the Atlas builder's tour no longer says placing lights is free (it needs a PadSpan Bright Pro or PadSpan Pro key); reading photos with no AI Task set up points to Settings → AI; the reference-power advice was the wrong way round; and the Factory Reset help lists what a reset keeps.

# Access points are placed in Mapping

### New
- **Wi-Fi access points on the Atlas.** With UniFi Utopia, each access point is a Home Assistant device, and Mapping places it like any other device: it has its own symbol and the "Wi-Fi" filter. The Wi-Fi coverage screen draws each one where it is placed (until then dashed, where the devices that hear it best suggest), and "Place in Mapping" opens Mapping with that access point selected.

### Changed
- **Wi-Fi coverage no longer drags access points.** One place to put them: Mapping.
- **The note under far-access-point findings** says devices differ in their transmitters and antennas, not only antennas.

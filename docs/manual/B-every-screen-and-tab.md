# Appendix B. Every screen and tab

[Contents](README.md)

Every screen in PadSpan's menu, in the menu's order, with its tabs. The table is read from the panel's
own code, so it names exactly what the panel shows in English. Which screens each mode (Basic,
Advanced, More tools) shows is in [chapter 12](12-the-screens.md#the-menu-map). Each screen's **?**
button explains it in the panel.

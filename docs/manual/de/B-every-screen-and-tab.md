# Anhang B. Jeder Bildschirm und jeder Reiter

[Inhalt](README.md)

Jeder Bildschirm in PadSpans Menü, in der Reihenfolge des Menüs, mit seinen Reitern. Die Tabelle wird
aus dem Code des Panels selbst gelesen, sie nennt also genau, was das Panel auf Englisch zeigt. Welche
Bildschirme jeder Modus (Einfach, Erweitert, Weitere Werkzeuge) zeigt, steht in
[Kapitel 12](12-the-screens.md#die-menükarte). Der **?**-Knopf jedes Bildschirms erklärt ihn im
Panel.

Die folgende Tabelle ist englisch: Sie entsteht direkt aus PadSpans Code.

# The PadSpan HA Manual

One manual for PadSpan HA, a chapter per page.

The help inside PadSpan (the **?** next to a heading) is in English, German, French and Dutch.
PadSpan uses the language set in your Home Assistant user profile, or Home Assistant's own language
when the profile has none; any other language shows English.

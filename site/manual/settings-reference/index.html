20. Settings reference

Contents

Every setting PadSpan keeps: where it is in the panel, its default, what it takes, and what it does. The tables are made from PadSpan's code by scripts/build_manual_reference.py (the defaults from settings_store.py, the ranges from ws_settings.py, the labels checked against the panel's own screens), and a test fails when they and the code disagree.

Before you change anything

  • Basic mode shows only Appearance. Settings' other tabs (Tracking, Features, AI, Atlas, UI Structure) are in Advanced and Development mode. The mode button at the top right switches between them.
  • Most settings save at once and take effect at the next update, with no restart. The ones that need more say so on their card (the Atlas's sidebar entry needs a Home Assistant restart; a newly ticked kind of entity needs PadSpan to reload).
  • With Enhanced security on (on for a new install), only a Home Assistant administrator can change PadSpan's shared setup. A few settings are an administrator's whatever it says: Enhanced security itself, the usage report, Vacation Mode, guest tags, the AI and the shared furniture library, who shows in Live Aboard, and ESPresense Companion's address.
  • Every setting is in PadSpan's backups, and a Factory Reset puts them back to these defaults (keeping your licence key). See chapter 22.
  • Keys are the names PadSpan stores each setting under in .storage/padspan_ha.settings. They are given for support and for reading a Diagnostics file; there is no need to edit the file.

"Range or choices" is what PadSpan keeps the value to: a number outside the range is moved to its end, and a word not on the list is refused or replaced. "empty" means nothing is set.
